## BUG-3: `BankAccount.transferTo` снимает деньги при переводе на замороженный счёт
| Поле        | Значение                                           |
|-------------|----------------------------------------------------|
| Тест-кейс   | TC-1.4.4                                           |
| Компонент   | `BankAccount.transferTo`                           |
| Окружение   | Java 21.0.2, JUnit 5.10.1, Maven, коммит `89e03777`|
| Серьёзность | High                                               |
| Приоритет   | High                                               |
| Статус      | Open                                               |

**Предусловия:** нет

**Шаги воспроизведения:**
1. Создать счёт: `new BankAccount("Alice", 300)`.
2. Создать счёт: `new BankAccount("Boris", 50)`.
3. Вызвать `B.freeze`.
3. Вызвать `A.transferTo(B,100)`.
4. Вызвать `A.getBalance` и вызвать `B.getBalance`.

**Фактический результат:** исключение выбрасывается, но деньги уже списаны, `getBalance(A)` возвращает `200` (до операции баланс был `300.0`), а `getBalance(B)` возвращает `50` (баланс не изменился).

**Ожидаемый результат:** Операция отклонена целиком`IllegalStateException`, `A.getBalance()` = `300.0`, `B.getBalance()` = `50.0`.

**Причина:** `transferTo` сначала вызывает `withdraw` у отправителя, затем `deposit` у получателя. Ошибка во втором шаге происходит после того, как первый уже выполнен, и отката нет.

**Последствия:** деньги отправителя исчезают: общая сумма на двух счетах уменьшилась с `350.0` до `250.0`.

**Автотест:** TC-1.4.4 помечен `@Disabled("BUG-3")` до исправления.
