## BUG-1: BankAccount принимает имя владельца из одних цифр

| Поле        | Значение                                                 |
|-------------|----------------------------------------------------------|
| Тест-кейс   | TC-1.2.10 (Найден при анализе кода,вне плана тестирования) |
| Компонент   | `BankAccount`, конструктор                               |
| Окружение   | Java 17.0.12, JUnit 5.10.1, Maven, коммит `718f8ed`      |
| Серьезность | Low                                                      |
| Приоритет   | Low                                                      |
| Статус      | Open, требуется уточнение требования                     |

**Предусловия:** нет

**Шаги воспроизведения:**
1. Вызвать `new BankAccount("1234",300)`.
2. Вызвать `getOwner()` у созданного объекта.

**Фактический результат:** счёт создаётся, `getOwner()` возвращает `"1234"`, исключения нет.<br>

**Ожидаемый результат:** вероятно, `IllegalArgumentException`. Требований к формату имени в документации нет, поэтому ожидаемое поведение нужно уточнить у аналитика.<br>

**Примечание:** проверка владельца счета в конструкторе ограничивается `null` и пустой строкой, формат не проверяется. Автотест TC-1.2.10 помечен `@Disabled` до решения по требованию.
